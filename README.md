# dominic-behrens.github.io

Static personal website for Dominic Behrens.

## Edit content

- Homepage: `index.html`
- Publications: `publications/index.html`
- Keep selected work on the homepage in sync with the full publications list.
- CV: `cv/index.html`
- Shared design: `styles.css`
- Palette preview: use the button at the top right to switch between dark green and cream. The light palette uses green text and `#3F6F8A` highlights. The choice is saved in this browser.
- Palette variables and button styles: `styles.css`; toggle behaviour: `theme.js`.
- Downloadable CV: `files/Dominic_Behrens_Resume (1).pdf`

There is no build step. Open `index.html` locally or use any static web server. GitHub Pages publishes the files directly.
